# Push Notifications — App Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ReTiCaMsgr can opt in to push wake-ups from a push-capable hub: a Settings toggle registers the device, a Notification Service Extension proves pushed packets and stashes them, and the app feeds stashed packets into ReTiCA's transport whenever it runs, so messages arrive through the normal receive path and senders get a standard proof.

**Architecture:** `AppFeature` scopes `PushFeature` from the `ReTiCAPush` package and turns its `delegate(.inject)` into `transport.received` on the TCP interface. A new `AppDelegate` (via `UIApplicationDelegateAdaptor`) owns `AppRuntime`, forwards the APNs token, handles the background wake and notification taps, and supplies the UIKit `PushPlatform`. A small `ReTiCaMsgrPushService` package target holds the app-group constant and builds the live `PushServiceHandler`, so the extension target links nothing but that. The Xcode project gains the extension target, an app group, the push entitlement and the `remote-notification` background mode.

**Tech Stack:** Swift 6 (packages) / Swift 5 mode with MainActor default isolation (app targets), TCA, SwiftUI (iOS 26.4), UserNotifications, ReTiCA (`Packet`, `Destination`, `LXMessage`, `InterfaceID`, `Transport.Action.received`), `ReTiCAPush` (`PushFeature`, `PushStorage`, `PushInbox`, `PushPayload`, `PushServiceHandler`, `PushPlatform`), Swift Testing, `xcodebuild`.

**Spec resolutions**
- The spec's `pushInbox`/`pushSettings` dependencies became `PushStorage` in `PushFeature.State` (package plan). `AppFeature.State.init` therefore takes `pushStorage:`, `bundleID:` and `pushEnvironment:` with defaults, so existing call sites and tests are untouched.
- `hubChanged` is forwarded wherever the app actually dials: `onLaunch`, `connectTapped` and `foregrounded` (when it re-dials), not on every keystroke in the host field. The hub the extension proves to is the hub the app last dialed.
- `pushWake` re-dials exactly like `foregrounded` and then drains. It does not touch `backgrounded`, which stays unused.
- The extension target links a package product, `ReTiCaMsgrPushService`, from the existing `ReTiCaMsgrCore` package reference, rather than referencing `ReTiCAPush` a second time from the Xcode project. That target depends only on `ReTiCAPushExtension`, so the extension never links TCA or SQLite.
- `AppRuntime.pushWake()` holds for `Environment.wakeHold` (20 s live, zero under `testHost()`), so hosted tests do not wait.

## Review Focus

Inputs the spec implies but no task's tests exercised until this list was written. Each line's test has been added to the owning task.

1. A pushed packet arrives while the TCP client slot exists but is disconnected. Injection must still happen (the transport decrypts; the proof is a no-op), so the message lands even without a socket. → Task 2, `pushAppInjectDeliversWhileDisconnected`.
2. The inject delegate carries several packets. Every one must reach the transport, in order. → Task 2, `pushAppInjectForwardsEveryPacketInOrder`.
3. A background wake arrives before first unlock, so the identity is locked and no store can be built. The fetch handler must complete `.noData` promptly, not hang for 20 s. → Task 3, `pushRuntimeWakeWithLockedKeychainReturnsFalse`.
4. A notification tap delivers a payload whose extension already stashed the packets. The tap handler's append must be a no-op, not a duplicate. → covered by `PushInbox` idempotency in the package plan; Task 3's `didReceive` uses `append`, which the package test pins.
5. The app launches with push enabled but the registration URL field empty. The token flow must fail with "Invalid registration URL" and leave the toggle on. → covered by the package plan's `pushFeatureTokenInvalidURLFailsWithoutPosting`; nothing app-side.

/// A HEADER_1 DATA packet carrying an opportunistic LXMF message from `sender` to `me`.
private func pushedPacket(from sender: Identity, to me: Identity, text: String) -> (raw: Data, message: LXMessage) {
    let message = LXMessage.create(source: sender, destinationHash: LXMessage.deliveryHash(identityHash: me.hash),
                                   timestamp: 1700000000.5, title: Data(), content: Data(text.utf8))
    let dest = Destination(kind: .single, direction: .in, appName: LXMessage.appName,
                           aspects: LXMessage.deliveryAspects, identity: me)!
    let packet = Packet.data(to: dest, plaintext: Data(message.packed.dropFirst(16)))
    return (try! packet.packed(), message)
}

/// token, and handles notification presentation and taps (spec 2026-10-01 §3.2).
final class AppDelegate: NSObject, UIApplicationDelegate, UNUserNotificationCenterDelegate {
    let runtime = AppRuntime(environment: .forProcess())

    func application(_ application: UIApplication,
                     didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil) -> Bool {
        UNUserNotificationCenter.current().delegate = self
        return true
    }

    // MARK: Token

    func application(_ application: UIApplication, didRegisterForRemoteNotificationsWithDeviceToken deviceToken: Data) {
        runtime.pushDeviceToken(deviceToken)
    }

    func application(_ application: UIApplication, didFailToRegisterForRemoteNotificationsWithError error: Error) {
        runtime.pushDeviceTokenFailed(error.localizedDescription)
    }

    // MARK: Background wake (content-available)

    func application(_ application: UIApplication,
                     didReceiveRemoteNotification userInfo: [AnyHashable: Any]) async -> UIBackgroundFetchResult {
        // The extension already stashed the packets. Stash again anyway (idempotent) in case it
        // was killed before writing, then wake the store.
        stash(userInfo)
        return await runtime.pushWake() ? .newData : .noData
    }

    // MARK: Presentation and taps

    func userNotificationCenter(_ center: UNUserNotificationCenter,
                                willPresent notification: UNNotification) async -> UNNotificationPresentationOptions {
        // Foreground: the message is about to appear in the UI, so no banner. Drain instead.
        if UIApplication.shared.applicationState == .active {
            stash(notification.request.content.userInfo)
            runtime.drainPushInbox()
            return []
        }
        return [.banner, .list, .sound]
    }

    func userNotificationCenter(_ center: UNUserNotificationCenter,
                                didReceive response: UNNotificationResponse) async {
        stash(response.notification.request.content.userInfo)
        _ = await runtime.pushWake()
    }

    /// Append the payload's packets to the inbox. A no-op for packets the extension already wrote.
    private func stash(_ userInfo: [AnyHashable: Any]) {
        guard let packets = try? PushPayload.decode(userInfo) else { return }
        let inbox = runtime.pushStorage.inbox
        for raw in packets {
            try? inbox.append(raw)
        }
    }

import UserNotifications
import ReTiCaMsgrPushService

/// Runs for every push with `mutable-content: 1` (spec 2026-10-01 §1, §3). Stashes the packets
/// and proves them to the hub, then hands back the ORIGINAL content: the banner always reads what
/// the server sent ("New message"). Nothing is decrypted here.
final class NotificationService: UNNotificationServiceExtension {
    private var contentHandler: ((UNNotificationContent) -> Void)?
    private var originalContent: UNNotificationContent?
    private var work: Task<Void, Never>?

    override func didReceive(_ request: UNNotificationRequest,
                             withContentHandler contentHandler: @escaping (UNNotificationContent) -> Void) {
        self.contentHandler = contentHandler
        self.originalContent = request.content
        let userInfo = request.content.userInfo
        guard let handler = ReTiCaMsgrPush.makeServiceHandler() else {
            finish()
            return
        }
        work = Task {
            await handler.handle(userInfo: userInfo)
            await MainActor.run { self.finish() }
        }
    }

    override func serviceExtensionTimeWillExpire() {
        work?.cancel()
        finish()
    }

    private func finish() {
        guard let contentHandler, let originalContent else { return }
        self.contentHandler = nil
        contentHandler(originalContent)
    }
}
